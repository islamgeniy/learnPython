# Python Learning Projects

This repository contains a collection of small Python projects built while learning and practicing core Python concepts.

The goal of this repository is not to showcase large production-level applications, but to document my progress in Python fundamentals, problem solving, and basic project structure.

## Topics Practiced

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and string operations
- Basic algorithms
- File organization
- Jupyter Notebook practice

## Projects

| Project | Description | Concepts Practiced |
|---|---|---|
| Caesar Cipher | A simple text encryption/decryption program | Strings, loops, functions |
| Seconds Converter | Converts seconds into readable time format | Arithmetic, functions |
| PIN Extractor | Extracts PIN-like patterns from input | Strings, conditions |
| Variable Detector | Determines variable-related input patterns | Conditions, validation |
| Sorting List | Sorts list elements using Python logic | Lists, sorting |
| Swap Elements | Swaps elements in a list | Lists, indexing |
